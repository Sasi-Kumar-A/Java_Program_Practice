## 💻 Running the Programs

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Sasi-Kumar-A/Java_Program_Practice.git
```

### 2️⃣ Open the project

Open the project using an IDE such as:

* Eclipse
* IntelliJ IDEA
* Visual Studio Code

### 3️⃣ Compile a Java program

```bash
javac FileName.java
```

### 4️⃣ Run the program

```bash
java FileName
```
